# Accounting Standards World Roadmap

Accounting Standards World is architecture and learning preview only in this release.

The roadmap covers the Conceptual Framework, presentation, recognition, measurement, disclosure and selected-standard cases. Every module must store an official reference, effective version, review status and review date before it can become Professional Assessment content.

Current modules are `Learning Preview` or `Review Required`. None is approved for professional assessment, and none creates Demonstrated or Verified evidence. The repository does not invent or paraphrase detailed IFRS requirements without a reviewed official source.
