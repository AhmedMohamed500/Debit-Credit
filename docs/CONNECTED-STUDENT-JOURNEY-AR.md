# ربط رحلة الطالب وإصلاح صورة البروفايل

التاريخ: 10 أكتوبر 2026.

## سبب المشكلة

- إطار الصورة كان 70×70 بكسل (55×55 على الموبايل)، لكن المكوّن بداخله كان دائرة 44×44؛ لذلك ظهرت مساحة ملونة حول الصورة.
- الصفحة الرئيسية عرضت تدريب الطالب وأول وردية والتشخيص المهني كمداخل متنافسة، مع روابط متعددة للملفات الشخصية. لم يكن هناك تسليم واضح بين المراحل.
- الصفحة الرئيسية الجديدة ورثت خلفية داكنة من العالم القديم، بينما النص يستخدم ألوان الوضع الفاتح. أُصلح ذلك بعد فحص صور المتصفح.

## السلوك الجديد

للطلاب المسجلين (بما في ذلك الحسابات التي لم تحدد المرحلة المهنية بعد):

1. إدخال البيانات الشخصية والتعليمية المطلوبة مرة واحدة.
2. إنهاء مهام ملف تدريب الأساس الإحدى عشرة داخل مدينة اللعبة ومكتبها وكمبيوتر المكتب.
3. الانتقال إلى أول وردية: ثلاث حالات مقبولة، وقيود يومية موجودة فعلًا، ومراجعة الأستاذ. إتمام الحالات الثلاث وحده لا يكمل المراحل الخمس.
4. مراجعة أدلة المهارات الناتجة عن العمل.
5. مراجعة وتصدير الـCV الإنجليزي، ثم متابعة المسار المهني وفق شروطه الحالية.

الرئيسية `/ar` و`/en` ومركز اللعب يقدمان للطالب نفس نقطة البداية وزرًا رئيسيًا واحدًا لاستكمال الخطوة الناقصة. الأدوات الإضافية تحت قائمة اختيارية. يظهر ترتيب الرحلة ومكان الطالب داخل صفحات التدريب واللعب والملف؛ في المهمة الحالية لا يوجد زر يعيد فتح الصفحة نفسها.

المهارات والـCV نتائج للعمل، وليسا مقررين جديدين، ولا تُضاف علامة إتمام أو توثيق مهني لمجرد زيارة الصفحة. يظل بالإمكان مراجعتهما مبكرًا، مع توجيه الطالب للعمل غير المكتمل. لا تتغير واجهة الدخول الأساسية للخريجين والمحاسبين العاملين أو الزوار.

## المسارات

| المرحلة | المسار داخل كل لغة |
| --- | --- |
| بيانات الطالب | `/{ar أو en}/student-profile` |
| تدريب الأساس | `/{ar أو en}/game/student` |
| أول وردية | `/{ar أو en}/game/first-shift` |
| أدلة المهارات | `/{ar أو en}/career-profile/skills` |
| السيرة الإنجليزية | `/{ar أو en}/career-profile/cv` |
| الملف والصورة | `/{ar أو en}/career-profile` و`career-profile/edit` |

تبديل اللغة داخل الملف المهني يحافظ على الصفحة الحالية، بما فيها صفحة الـCV، بدل العودة دائمًا إلى مقدمة الملف.

## البيانات والخصوصية

- يعتمد تدريب الأساس على النتائج المحفوظة من الخادم، وتستند أول وردية إلى تقدم اللعبة الحالي ومعايير المراحل الخمس الموجودة أصلًا.
- تُحدث الإرشادات بعد إرسال المهمة وعند التنقل؛ عند تعذر تحميل التقدم يظهر زر إعادة المحاولة، لا زر بداية يستند إلى افتراض إتمام.
- تُربط نتيجة التحميل بمالك الحساب، وتُلغى الاستجابات المتأخرة عند تبديل الحسابات.
- لم يتغير مخطط قاعدة البيانات أو حسابات المستخدمين أو دفاتر المحاسبة أو تقييم الإجابات؛ ولم تُدمج دفاتر الشركتين التدريبيتين.
- الصورة تملأ إطارها مع قص متناسب. يظل ملفها الخاص 512×512، دون بيانات EXIF، ولا تُضاف إلى الـCV المتوافق مع ATS.
- الاختبارات ذات الكتابة تستخدم PostgreSQL وحسابات محلية معزولة فقط. اختبار الإنتاج قراءة فقط ولا ينشئ حسابات.

## التحقق

`npm run check` يشمل lint وTypeScript والاختبارات وبناء الإنتاج. أضيفت اختبارات لترتيب المراحل واللغتين والتكرار والحسابات وعدم اختلاق التوثيق ومراجعة الأستاذ.

`scripts/student-cv-browser-qa.mjs` يفحص العربية والإنجليزية على 1440 و390 بكسل، ويقيس ملء الصورة للإطار، ويستكمل المهام الإحدى عشرة. يتضمن في الإنجليزية على الكمبيوتر تسلسلًا حقيقيًا لتحقيق الحالات الثلاث وترحيلها ومراجعة اليومية والأستاذ ثم المهارات والـCV. يتحقق أيضًا من استعادة الخطوة التالية بعد خروج ودخول جديدين.

`scripts/auth-routing-browser-qa.mjs --signup-signin-home` يعيد فحص التسجيل ثم الدخول والرئيسية والخروج. تنتظر أداة تجهيز بيانات الاختبار شريط الحساب الجاهز قبل الكتابة في النموذج، حتى لا تستهدف نموذج SSR المؤقت قبل تهيئة جلسة المتصفح.

صور وتقارير الاختبار محلية في `artifacts/` وليست جزءًا من الملفات المنشورة. لم تُستخدم بيانات طالب حقيقي في الاختبارات.
