التاريخ: 2026-09-29
الفرع: `codex/career-league`
آخر تعديل بصري: `ab79220` — `Build cinematic First Shift mission world`

## النتيجة

استُبدلت واجهة البطاقات الفاتحة في مدخل «أول وردية» بعالم بصري داكن مستوحى من المرجع: مدينة أعمال زرقاء، مسار مضيء وشخصية من الخلف، عنوان مركزي، خمس بوابات مهام ملوّنة، لوحة **Mizan OS**، لوحة المكافآت، وخطوات اللعب. البوابات والأزرار والتقدم ليست جزءًا ثابتًا من الصورة؛ إنها عناصر React وCSS مرتبطة بحالة اللعبة. الخلفية المصورة هي `public/game/first-shift-city-v2.png`.

المسار: `/ar/game/first-shift`، وبالإنجليزية `/en/game/first-shift`.

## مكونات الشاشة

| العنصر | السلوك |
| --- | --- |
| عنوان «أول وردية لك» | يشرح الوردية ويبدأ أول حالة غير مكتملة. |
| بيانات Mizan Trading | تعرض الشركة ومستوى اللاعب ومحطات التقدم. |
| ثلاث بوابات مستندات | فاتورة مورد، سند قبض عميل، مصروف مكتب؛ تفتح الحالات الفعلية. |
| دفتر اليومية | يفتح اليومية لمراجعة القيود. |
| دفتر الأستاذ | يفتح بعد وجود أول قيد؛ حالة القفل ظاهرة قبل ذلك. |
| Mizan OS | يعرض حالة المحطات وملفات الوارد والمعالجة. |
| المكافآت وخطوات اللعب | تشرح XP والخبرة والمهارات وتسلسل المعالجة. |

التقدم يُحسب من العمل المكتمل، لا من فتح الشاشة. قيود اليومية المقبولة محمية بقواعد المحرك القائم، والدليل المهني منفصل عن نقاط اللعب. التخزين محلي في المتصفح؛ هذا ليس نظام ERP أو ترتيب لاعبين حيًا.
