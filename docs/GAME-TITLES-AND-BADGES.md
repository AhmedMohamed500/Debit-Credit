# Game Titles and Badges

V2 awards are deterministic local gameplay identity only: First Duel after a completed duel; First Perfect Case for a ranked 100/100; Boss Case for an approved ranked boss result; Three-Day Streak after three dated ranked sessions; Risk Guardian after three high-risk-awareness ranked cases; Document Detective after three fully investigated ranked cases. The profile displays only earned awards. No random drops, loot boxes or paid advantages exist.

These labels are not job titles, certifications, verified assessment or Skill Passport evidence. The currently linked full boss missions do not yet write a dedicated ranked boss result, so the Boss Case award is architecture-ready but not earnable from those links today. Competition placement also never adds an ATS CV bullet automatically.
