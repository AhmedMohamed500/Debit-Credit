# Local Career League and Offline Competition

## Honest mode

Career League is currently a local or demo competition. The system does not claim real online players, real-time standings, verified identity or cross-device sync.

## Challenge identity

Every comparable challenge carries:

- Challenge ID
- Challenge Version
- Ruleset Version
- deterministic Seed
- Case ID
- Difficulty
- Issue date

Daily Challenge generation is deterministic by date, level and specialist track.

## Professional score

The score weighs accuracy, judgment, investigation, risk awareness, first-attempt quality and difficulty. Manager assistance reduces the score. Speed has no direct reward. This makes careful work score above rushed unsafe work.

## Offline result package

A local result package contains the player label, exact challenge identity, performance dimensions, assistance used, completion time and an integrity checksum. The checksum detects accidental or simple manual edits; it is not a cryptographic signature and does not create Verified evidence.

## Local Duel

Two result packages are comparable only when Challenge ID, Challenge Version, Ruleset Version and Seed match exactly. Professional score decides the result; accuracy breaks a score tie. Otherwise the duel is a tie.

## Fair leagues

Weekly standings compare profiles only inside the same simulation level and specialist track. They use validated local result packages and display game titles such as Career Starter, Evidence Builder and Control Guardian. These titles are game progression labels, not employment titles.
