# البروفايل الموحد والكورسات والشهادات

تحديث 10 أكتوبر 2026. البروفايل الجديد للحساب المسجل، سواء طالبًا أو خريجًا أو محاسبًا عاملًا أو صاحب خبرة، على `/ar/career-profile` و`/en/career-profile`. واجهات الضيف والـCV وجواز المهارات ومعاينة صاحب العمل تحتفظ بوظائفها الحالية.

## التصميم والربط

- نفس عائلة ألوان المرجع: خلفية أزرق ثلجي فاتح `#eaf6fa`، بطاقات بيضاء، بترولي `#143c47` و`#1e6267`، تركواز `#4b9a8b` وذهبي هادئ `#c4b16d`.
- صورة كبيرة تملأ الدائرة، اسم حقيقي، عنوان مهني ومقياس **اكتمال البيانات الشخصية** وليس نسبة مهارات مختلقة.
- أقسام البروفايل والكورسات والتقدم والشهادات، مع قائمة جانبية وروابط فعلية للعب والـCV والدليل.
- أخفي شريط رحلة الطالب الكبير في صفحة البروفايل فقط لتجنب تكرار التنقل. زر «كمّل رحلتي» يصل إلى الخطوة التالية المحفوظة للطالب، وإلى الرئيسية لباقي الشخصيات أو عند تعذر تحميل الرحلة.
- العربية RTL بخط Cairo المحلي؛ الإنجليزية LTR. ألوان البروفايل ثابتة حتى لو تغير إعداد الثيم العام.
- نشاط حديث من سجلات الأدلة الفعلية، مع منع تكرار الحدث بسبب تعدد إسقاطاته على المهارات. لا اختلاق كورسات أو شهادات أو مواعيد نشاط.

## البيانات والكورسات

البيانات الشخصية والتعليم والخبرة الفعلية مرتبطة بالملف الموجود. البريد مصدره الحساب نفسه. تعديل البيانات التفصيلية يستمر عبر واجهات الإعداد الموجودة؛ رفع الصورة وإزالتها متاحان داخل البروفايل. صورة البروفايل 512×512 وتبقى خارج CV الـATS.

إضافة وتعديل وحذف حتى 20 كورسًا خارجيًا: الاسم، جهة التدريب، شهر الكورس الاختياري، الحالة «لم يبدأ / جارٍ الدراسة / مكتمل»، وملاحظات ما تم تعلمه. هذه **بيانات مضافة من صاحب الحساب**، وليست تقييم منصة. لا نعرض نسبة تقدم رقمية وهمية للكورسات الخارجية.

تقدم أساسيات المحاسبة يأتي من نتائج المهام المقبولة بالخادم (11 مهمة)، وتقدم الوردية من مهام المحاكاة الخمس بما فيها اليومية والأستاذ. البيانات غير المحملة تظهر «—» لا صفرًا زائفًا. الدورات الخارجية لا تغيّر النقاط أو أدلة المهارات.

## صور الشهادات والخصوصية

- حتى 20 شهادة: الاسم، الجهة المانحة، شهر الإصدار ورقم الشهادة الاختياريان، وصورة إلزامية.
- JPG / PNG / WebP حتى 5MB قبل تجهيز الصورة بالمتصفح. لا دعم PDF أو SVG أو GIF أو رابط صورة خارجي.
- أقصى ضلع محفوظ 1600 بكسل مع الحفاظ على المستند كاملًا ونسبة أبعاده؛ لا قص مربع للشهادات.
- الخادم يفحص البكسلات الحقيقية ويعيد ترميزها WebP دون EXIF/GPS، ويرفض الصور التالفة والرسومات المتنكرة والرسوم المتحركة ومدخلات البكسلات الضخمة. تجهيز المتصفح ليس بديلًا عن فحص الخادم.
- الأصل لا يُحفظ؛ تُحفظ النسخة المعالجة فقط. حد الصورة المشفرة 900,000 حرف وحد جسم طلب API هو 950,000 بايت.
- العرض الخاص عبر نافذة حوار أصلية تدعم لوحة المفاتيح وEscape. حذف الشهادة بعد التأكيد يحذف صورتها المخزنة نهائيًا؛ لا يُزعم وجود سلة استرجاع.
- كل شهادة موسومة «مرفوعة · غير موثقة». الرفع ليس تحققًا من الجهة المانحة ولا يمنح Verified أو خبرة توظيف.
- الصور والبيانات الخارجية لا تدخل ترتيب المنافسات أو التصدير العام للتقدم أو معاينة صاحب العمل. لا تُضاف صور الشهادات إلى الـCV بنظام ATS.
- هذا الإصدار يدير بيانات الكورسات والشهادات في البروفايل؛ لا يضيفها تلقائيًا إلى محرك الـCV الإنجليزي. أدلة مهام المحاسبة المقبولة تواصل تحديث الـCV كما سبق.

## API والتخزين

| المسار | السلوك |
| --- | --- |
| `GET /api/v1/me/portfolio` | قائمة بيانات كورسات وشهادات الحساب، دون تحميل صور المستندات |
| `PUT /api/v1/me/portfolio` | أوامر محددة، تحقق Zod صارم، حارس revision، Origin، تحديد معدل طلبات وحارس الحساب القديم |
| `GET /api/v1/me/certificates/{uuid}` | الصورة المعالجة الخاصة بمالك الجلسة؛ حساب آخر يحصل على 404 |

يُستخدم `CloudProgress` الموجود بمجالات `private-portfolio` و`private-certificate/{uuid}`؛ لا نموذج Prisma جديد ولا migration أو reset لقاعدة البيانات. الاستعلامات تستخدم هوية الجلسة، وليس `userId` من العميل. يُرفض حقن هوية المالك أو حالة تحقق إضافية. الحفظ والحذف داخل transaction Serializable، والصور مستبعدة من `me/progress`.

كل رد خاص `Cache-Control: private, no-store`. حالة Logout لا تتيح قراءة القائمة أو الصورة؛ أسماء UUID ليست تصريح وصول.

## التحقق

- اختبارات جديدة للتحقق من الأوامر، حدود التخزين، تعديل الكورسات، الفصل بين الحسابات، تنقية الصور، الحذف، والواجهة العربية ومختلف مستويات الخبرة.
- `npm run check`: lint + TypeScript + 598 اختبارًا / 70 ملفًا + production build.
- `node scripts/student-cv-browser-qa.mjs`: نجح 432 فحصًا دون أخطاء تشغيل؛ PostgreSQL محلية معزولة وحسابات اختبار فقط، تغطي التسجيل والمحاسبة والـCV بجانب الكورسات والشهادات على العربية/الإنجليزية و1440/390px والشخصيات الأربع. التقارير والصور تحت `artifacts/student-cv/` ومستبعدة من Git.
- اختبار الإنتاج قراءة فقط: المسارات المحمية وتحويلها إلى تسجيل الدخول ورفض واجهات الصور والبيانات دون جلسة؛ لا رفع شهادات حقيقية ولا إنشاء حسابات اختبار على الإنتاج.

لا تغيير لنظام Better Auth أو الدفاتر المحاسبية أو بيانات الإنتاج أو أسرار النشر.
