# صفحة التسعير — تنفيذ المرجع النهائي

## المسارات

- العربية: `/ar/pricing`
- الإنجليزية: `/en/pricing`

أُضيف رابط التسعير إلى تنقل صفحة التسويق، وإلى قائمة المسارات العامة وملف sitemap. صفحة التسعير تحتفظ برأس تنقل مستقل بتكوين الصورة المعتمدة. لا تغيّر الصفحة بيانات الحسابات أو صلاحياتها أو المحرك المحاسبي.

## التكوين

- الخلفية: جبال زرقاء، متسلق بحقيبة، طريق ذهبي مضيء، ولافتات المراحل المعروضة كعناصر HTML.
- العنوان، صندوق المميزات، محدد الجمهور، موجة نهاية الهيرو، ومحدد الفترة عناصر واجهة فعلية قابلة للتجاوب.
- أربع بطاقات في شبكة متساوية الأعمدة والارتفاع على سطح المكتب: مجاني، Pro شهري، Pro سنوي، رحلة المستخدم. بطاقة الرحلة معلوماتية وليست خطة مدفوعة.
- بعد البطاقات: اقتباس مع العلامة، جدول مقارنة موجز، ورسالتان صادقتان عن المنتج بدل تقييمات أو شهادات مستخدمين مختلقة.

## الأسعار وحدود الإتاحة

الأسعار المعروضة **مقترحة** وليست فاتورة أو اشتراكًا مفعّلًا: 129 جنيه شهريًا و899 جنيه سنويًا. لو دفع شخص 129 جنيهًا في كل شهر لمدة سنة، يدفع 1548 جنيهًا؛ الفرق 649 جنيهًا، أي نحو **42%**. محدد شهري/سنوي يعرض الخطة المختارة وسعرها ويغيّر شارة التوفير وإطار البطاقة؛ ولا يُخفي أيًا من بطاقتي Pro.

زر الخطة المجانية يصل إلى التسجيل/البدء الحالي. زر كل خطة مدفوعة يُظهر رسالة صريحة بأن الدفع والاشتراك غير متاحين الآن؛ لم يُنشأ مسار دفع أو اشتراكات أو صلاحيات وهمية. عند اختيار شركة/مؤسسة، يظهر شرح النسخة التجريبية لأصحاب العمل ورابطها الحالي. جدول المقارنة يعرض الميزات المتاحة اليوم لكل الخيارات دون افتراض حجبها مستقبلًا.

## الصورة

الأصل الزخرفي فقط: `public/pricing/mountain-journey.png`، أُنشئ باستخدام أداة الصور المدمجة انطلاقًا من مرجع المستخدم الأخير. نص الطلب: «مشهد بانورامي نظيف لهيرو صفحة التسعير؛ جبال زرقاء وشخص يحمل حقيبة في أسفل اليسار وطريق ذهبي مضيء يصعد إلى القمة وأعلام صغيرة؛ تدرج كحلي/بترولي/تركوازي، مع مساحة داكنة هادئة يمينًا للنص الحقيقي. احذف كل الكلمات والشعارات والأرقام واللافتات والأزرار والبطاقات واللوحات وعناصر الواجهة؛ دون مكتب أو حاسوب». تختلف تفاصيل الرسم عن الصورة المرجعية لأن الأصل الزخرفي أُعيد توليده؛ النصوص والبطاقات تُرسم من الكود.

## التحقق

شغّل `npm run check` و`npm run build`، ثم `node scripts/pricing-browser-qa.mjs`. يحفظ فحص المتصفح صور العربية والإنجليزية على 1920×1080 و1440×900 و1024×900 و390×844 داخل `artifacts/pricing-reference/qa/`، مع صورة الوضع الداكن. يفحص تساوي العرض والارتفاع والفجوات ومحاذاة الأزرار على سطح المكتب، وعدم تجاوز عرض الصفحة، وتبديل الفترة والجمهور، وبيان عدم إتاحة الدفع.

للتفاصيل الكاملة عن إصلاحات التنسيق والتبديل، وسلوك الخطط، والملفات، والاختبارات، انظر [تقرير إصلاح صفحة التسعير](./PRICING-PAGE-FIX-AR-2026-10-14.md).
