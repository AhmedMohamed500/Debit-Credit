# Phase A — مراجعة تكامل المنتج

التاريخ: 2026-09-26. النطاق: النسخة المحلية ثنائية اللغة قبل أي توسعة لـBank Track. المراجعة اعتمدت على المسارات والمكونات والمستودعات والاختبارات الموجودة؛ لم تُحذف بيانات مستخدم أو مفاتيح حفظ.

## الخلاصة التنفيذية

كان المسار المهني موجودًا بالفعل، لكن عرضه لم يكن متسقًا في ثلاث نقاط: قسم الجمهور التسويقي يعرض ثلاث شخصيات فقط وأزراره تبدأ دخولًا عامًا؛ شريط التنقل الداخلي يعرض «الأكاديمية/الوارد» قبل المفاهيم الأساسية للمستخدم؛ وGame Hub لا يجيب في موضع واضح عن «ماذا أفعل الآن؟». كذلك كانت منطقة البنك القديمة تصف التسوية بأنها مقفولة رغم وجود ورقة عمل قابلة للعب. أصلحنا الربط والعرض، وأبقينا نظام الأدلة وملفات الحفظ كما هو.

## نتائج الأسئلة العشرة

- الصفحات المهنية كلها لها غرض ومخرج واضح في جدول المسار أعلاه؛ ما يزال انتقال بعض المسارات المتقدمة مقيّدًا عمدًا لعدم وجود محتوى قابل للعب.
- لا نخلط الإحصاءات التنافسية مع الأدلة: XP والمستوى في ملف اللعبة؛ Skill Passport والـCV والـGap في المسار المهني. أي نسبة جاهزية تظهر فقط وفق قواعد الأدلة القائمة.
- المسارات القديمة ذات الاستخدام المحتمل لم تُحذف. استُخدم Redirect للبنك فقط لأن صفحة المنطقة كانت تكرر حالة العميل وتضلل بشأن حالة التسوية.
- وعود المحتوى المستقبلي ظاهرة بحالة «قيد التطوير/مقفول»؛ لا يوجد Backend أو اعتماد توظيف أو لاعبين عالميين.
- المخاطرة المتبقية: لا يوجد بعد مسار احترافي متكامل B01–B11 أو تسلسل إقفال شهري قابل للعب؛ ذلك Phase C لاحقة، وليس جزءًا من هذه الدفعة.

## سلامة البيانات

لم نغير شكل `CareerLeagueState` ولا مفاتيح `localStorage` ولا نتائج Placement ولا مخطط الأدلة. منطق Game Hub يقرأ المستودعات القائمة ويُرشّح الأدلة بمعرّف المرشح المحلي. الاختبارات القديمة للهجرة والعزل بقيت ناجحة.
