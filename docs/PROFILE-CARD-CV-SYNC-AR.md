# كارت البروفايل وربط السيرة المختصرة — 11 أكتوبر 2026

## طلب المستخدم وما تغيّر

الكارت يتكون من بيانات البروفايل الحقيقية والصورة والروابط وQR، بنفس البترولي والتيل والذهبي. السيرة الإنجليزية مرتبطة ببيانات الحساب والكورسات والشهادات والتقدم، وليست قائمة طويلة لكل تاسك. الحد المطلوب لهذا المنتج صفحتان A4؛ ليس ادعاء بوجود معيار عالمي يلزم كل السير الذاتية بصفحتين.

### الكارت المهني

- معاينة خاصة داخل `/ar/career-profile` أو `/en/career-profile`، وتنزيل PNG بحجم 1600×1100.
- الاسم والدور المستهدف والتوفر المعلن وروابط LinkedIn وGitHub وFacebook وInstagram والموقع تأتي من البيانات المحفوظة، والصورة من رفع الحساب الحالي. تحديث الصورة ينعكس على الكارت دون إلغاء اختيار إخفائها.
- لا يدخل الكارت صورة طالب آخر عند تغيير الحساب. يمكن تنزيله بدون الصورة.
- QR يتكون محليًا من الرابط الحقيقي الذي فعّله المستخدم. لا خدمة خارجية، ولا رابط وهمي، ولا تفعيل أو نشر تلقائي. يجب تفعيل رابط المشاركة قبل تنزيل الكارت.
- صورة PNG تعرض الروابط كنصوص؛ ليست أزرارًا قابلة للنقر. يمكن مسح QR أو استخدام الروابط في معاينة الكارت داخل الموقع.
- الكارت المنزّل يحتوي الاسم والروابط والصورة الاختيارية؛ اختيار حقول الصفحة العامة يحدد ما يظهر **عند فتح QR**، وليس ما يُطبع في الصورة. الواجهة توضح الفرق قبل التنزيل. لا يمكن إلغاء نسخ صورة سبق مشاركتها.
- الصفحة العامة تبقى بدون صورة أو تليفون أو بريد أو شهادات خاصة أو نسخة CV. لا تتغير قواعد اختيار الحقول أو إلغاء الرابط.
- بطاقة إنجاز المهمة القديمة 1200×900 موجودة بجانب الكارت المهني، مع توضيح أن الإنجاز محاكاة تدريبية، لا توظيف أو اعتماد مهني.

### مصدر السيرة الإنجليزية

`GET /api/v1/me/cv?role=<role-id>` يشتق نسخة الحساب الحالية، داخل transaction قراءة متسقة، من:

1. بيانات الحساب الشخصية والتعليم والخبرة الفعلية، مع بريد الجلسة المعتمد.
2. كورسات وشهادات البروفايل المحفوظة، بما فيها المدخلة قبل هذا الإصدار.
3. أدلة التاسكات المقبولة المحفوظة على السيرفر.
4. إسقاط First Shift الموجود سابقًا من نسخة لعبة صاحب الحساب المحفوظة؛ يظل محاكاة، ولا ينشئ دليلًا رسميًا أو Verified أو نتيجة منافسة.

لا يعتمد المستخدم المسجل على نسخة محلية بديلة عند فشل قراءة حسابه. التنزيل يتوقف حتى ينجح التحديث. الضيف يحتفظ بالتجربة المحلية السابقة.

- إضافة الكورس أو تعديل حالته أو حذفه، وإضافة أو حذف شهادة، تعيد اشتقاق نسخة CV في نفس transaction الحفظ. فتح السيرة يجلب بيانات الحساب الحالية دون زر «إنشاء».
- حفظ البيانات الشخصية وروابط المعرض والتقدم المشمول يحدّث النسخة كذلك. قراءة GET لا تنشئ نسخ تاريخية ولا تنفذ backfill أو migration.
- LinkedIn والموقع حقلا تواصل مهنيان مشتركان بين محرر البيانات والمعرض؛ تعديل الروابط الصالحة في أي منهما ينعكس على الآخر وعلى CV. باقي السوشيال لا تُضاف إلى ATS CV. الروابط القديمة التي لا تجتاز قواعد المشاركة الآمنة لا تُنسخ إلى العرض العام.
- تحديث الرابط لا يفعّل المشاركة. لو فعّل المالك مشاركة السوشيال سابقًا، تعرض الصفحة روابطه الحالية كما هو متوقع، مع بقاء الاختيارات والتوكن الخاص به.
- revision يمنع استبدال تعديل تبويب آخر؛ عزل الجلسة وOrigin وحدود الطلبات تبقى كما هي.

### الاختصار وحدود المحتوى

- عمود نصي واحد، عناوين إنجليزية قياسية، بدون الصورة أو QR أو XP أو نسب اكتمال البيانات أو درجات ATS تسويقية.
- بيانات التواصل، ملخص قصير، أحدث ثلاث خبرات، تعليمان، المهارات المدعومة، ست نتائج محاكاة مختلفة كحد أولي، ستة كورسات، أربع شهادات، اللغات والروابط المهنية.
- القيود الستة في الوحدة الأولى تختصر إلى نتيجة واحدة مدعومة، بدل ستة فقرات متكررة. الأستاذ وميزان المراجعة وفحوص الجداول نتائج منفصلة. الأدلة الكاملة تبقى في ملف المهارات، ولا تُحذف.
- الكورس الذي لم يبدأ لا يظهر. Started/Completed يظهرا بالحالة الفعلية تحت `Courses (self-reported)`؛ شهادة صاحب الحساب تظهر كبيانات نصية `Certificates (self-reported)`، لا صورتها أو رقمها الخاص، ولا تحقق من اعتمادها.
- يمكن الاحتفاظ باسم الكورس وجهته بالعربية في البروفايل، مع حقلي اسم الكورس والجهة بالإنجليزية للـCV. الأسماء العربية غير المترجمة تحفظ في البروفايل ويظهر تنبيه بدل اختلاق ترجمة. بيانات CV الشخصية الجديدة مطلوب إدخالها بالإنجليزية.
- ميزانية محتوى محافظة ثم قياس DOM بعرض الطباعة الحقيقي 186mm، وبنفس خط Arial 10.5pt. التقسيم لا يزيد على صفحتين ولا يصغر الخط أو يقص النص.
- السجلات الزائدة تظل محفوظة ويظهر عددها في الواجهة. نسخة النص تطابق المحتوى المختار الظاهر، وليست dump لكل البيانات.
- الطباعة A4 بهوامش 12mm، مع رقم الصفحات. حجم الشاشة لا يغير قياس تقسيم الطباعة؛ العرض متجاوب للموبايل.
- لا ضمان لتقييم ATS أو قبول وظيفة؛ هذه صياغة مختصرة وواضحة من حقائق المستخدم والأدلة التدريبية المتاحة.

## التحقق وحدود النشر

- `npm run check` نجح: lint وTypeScript و621 اختبارًا في 73 ملفًا وبناء الإنتاج، بما فيه login/signup وBetter Auth وCV والمشاركة.
- `node scripts/student-cv-browser-qa.mjs` نجح: 668 فحصًا، بلا أخطاء تشغيل، بالعربية والإنجليزية على 1440/390 بكسل مع فحص 320 بكسل للعرض العام. يشمل CRUD الكورسات والشهادات وانعكاسها على CV، حفظ الأسماء الإنجليزية، خصوصية الصور والتوكن، تبديل الحساب، وإلغاء المشاركة.
- خمسة ملفات PDF فعلية فُحصت بواسطة pypdf وPoppler مع مراجعة كل الصفحات المصورة: أربع حالات عادية صفحة واحدة لكل منها، والحالة كبيرة المحتوى صفحتان. النص الإنجليزي قابل للاستخراج، والخط 10.5pt دون تقليص أو قص. كشفت المراجعة خلفية زائدة في حاوية الطباعة؛ أُصلحت ثم أُعيدت الحزمة كاملة. PNG الكارت الحقيقي 1600×1100 وبطاقة الإنجاز 1200×900 خضعا للفحص كذلك.
- النشر يتم عبر GitHub وتكامل Vercel القائم؛ SHA ونتيجة النشر وفحوص الإنتاج القراءة فقط تُسجل في طلب الدمج. لا يُستدل على نجاح الإنتاج من نجاح بناء محلي، ولا تُكتب fixtures في الإنتاج.
- كل حسابات وصور وشهادات QA وهمية في PostgreSQL محلي مستقل. الملفات تحت `artifacts/` مستبعدة من Git. لا قراءة أو نشر أسرار أو بيانات شخصية حقيقية، ولا تغيير schema أو reset لقاعدة الإنتاج.
