# ملف البروفايل الشامل — التغييرات والتشغيل والخصوصية وربط السيرة الذاتية

> مرجع ميزات البروفايل قبل توسعة منصة المواهب. أحدث التبويبات والثيم واكتشاف الشركات وصلاحياته موثقة في [CAREER-TALENT-PLATFORM.md](CAREER-TALENT-PLATFORM.md). لا تعتمد وصف العرض القديم هنا باعتباره الواجهة الجديدة.

تاريخ التوثيق: **11 أكتوبر 2026**. المشروع: `AhmedMohamed500/Debit-Credit`.

هذه الوثيقة تجمع تغييرات البروفايل من إعداد بيانات الطالب والصورة، إلى البروفايل الموحد والكورسات والشهادات والسوشيال والأعمال والكروت وQR والسيرة الإنجليزية المختصرة. تصف الحالة الحالية، وتفصلها عن التقارير التاريخية والميزات غير المنفذة. لا تحتوي بيانات مستخدم حقيقي أو مفاتيح أو رابط اتصال قاعدة بيانات.

## 1. الخلاصة الحالية

البروفايل أصبح نقطة تجمع مترابطة، لا صفحة منفصلة عن التعلم: بيانات صاحب الحساب وتعليمه وخبرته الفعلية، صورته، كورساته وشهاداته الخاصة، تقدمه المحاسبي المقبول، أفضل أعماله التدريبية، وروابطه المهنية. السيرة الإنجليزية تستخدم مصادر الحساب نفسها وتُحدّث عند حفظ التغييرات المشمولة.

- التصميم ثابت بالبترولي والتيل والذهبي والأزرق الثلجي، مطابق لعائلة ألوان المرجع المطلوبة.
- الواجهة مناسبة للطالب والخريج والمحاسب العامل وصاحب الخبرة، وليست مقتصرة على الطالب.
- كارت مهني بالصورة الاختيارية والروابط وQR، وبطاقة إنجاز منفصلة للمهارة المثبتة.
- مشاركة عامة باختيار المالك؛ الأصل خاص، ولا تُنشر الصورة أو التليفون أو البريد تلقائيًا.
- CV إنجليزي نصي بحد أقصى صفحتين A4، دون حشو كل التاسكات أو صور أو QR.
- آخر إصدار وظيفي موثق دُمج ونُشر عبر GitHub وتكامل Vercel. إنشاء هذا الملف وحده لا يعني نشر إصدار جديد.

**تصحيح مهم للتقارير القديمة:** تقرير البروفايل الأول كان يقول إن الكورسات والشهادات لا تدخل CV تلقائيًا. هذا وصف للإصدار القديم فقط؛ الإصدار الحالي يربط بياناتها النصية المناسبة بالسيرة، مع مراعاة اللغة والحالة وحدود الصفحتين.

## 2. ما تغيّر عبر مراحل العمل

| المشكلة أو الطلب | التغيير المنفذ |
| --- | --- |
| صورة صغيرة داخل إطار كبير | صورة تملأ الإطار، ثم هيرو بروفايل بصورة دائرية كبيرة |
| المستخدم تائه بين صفحات وأزرار كثيرة | أقسام واضحة وروابط فعلية وزر متابعة للخطوة المحفوظة، وإخفاء شريط الرحلة المكرر داخل البروفايل |
| بيانات CV منفصلة عن التسجيل | إعداد شخصي خاص بعد تسجيل الدخول، يستخدمه البروفايل والسيرة |
| الحاجة إلى بروفايل للطالب والعامل والخريج | بروفايل موحد مع التعليم والخبرة الفعلية والدور المهني |
| إدخال كورسات وصور شهادات | إدارة كورسات خاصة ورفع صور شهادات خاصة مع حماية المالك |
| افتقاد السوشيال والأعمال الجذابة | روابط آمنة، أفضل ثلاثة أعمال، ملخص قدرات مثبتة، بطاقات إنجاز |
| كارت بالصورة واللينكات والباركود | كارت مهني من البيانات الفعلية مع QR لرابط عام حقيقي يفعّله المالك |
| الكورسات غير ظاهرة في السيرة | ربط مباشر بالمصدر المحفوظ، وأسماء إنجليزية اختيارية للكورسات العربية |
| CV طويل ومكرر | تلخيص النتائج، اختيار محتوى مناسب، قياس الطباعة وتقسيمها إلى صفحتين كحد أقصى |
| تمارين جداول منفصلة عن اللعب | ورقة عمل داخل كمبيوتر المكتب بالمحاكاة؛ نواتج التعلم المقبولة ترتبط بالتقدم والسيرة |

الألوان لا تتغير بسبب تبديل الثيم العام. العربية RTL بخط Cairo المحلي، والإنجليزية LTR، مع عرض متجاوب للموبايل.

### مكونات البروفايل

- هيرو يعرض الصورة والاسم الحقيقي والعنوان المهني ومعلومات التوفر الاختيارية.
- مقياس اكتمال **البيانات الشخصية**؛ اكتماله ليس شهادة مهارة أو جاهزية للتوظيف.
- أربعة تبويبات: البروفايل، الكورسات، التقدم، الشهادات.
- قائمة جانبية وروابط فعلية إلى اللعب والتعلم والسيرة الإنجليزية ودليل المحاسبة.
- تبويب الصفحة يُحفظ في URL hash حتى يستمر الاختيار بعد إعادة التحميل.
- آخر نشاط من الأدلة الحقيقية؛ الحدث الذي ينتج عدة مهارات لا يظهر كأنها عدة أنشطة مختلفة.
- عند عدم تحميل بيانات التقدم يظهر «—»، وليس صفرًا مختلقًا.
- زر متابعة الرحلة يذهب إلى المرحلة التالية المحفوظة للطالب، وإلى الرئيسية لباقي الشخصيات أو عند تعذر قراءة الرحلة.

معاينة الضيف المحلية القديمة باقية للتوافق؛ لا تتيح إدارة الكورسات والشهادات والصور الخاصة بحساب آخر.

## 4. التسجيل والبيانات الشخصية والخبرة

المسار المقصود: **Sign up → Sign in منفصل → استكمال البيانات الشخصية عند الحاجة → الرئيسية → متابعة التعلم**. الحساب الذي لديه بيانات صحيحة محفوظة لا يعيد الإعداد من البداية.

بيانات السيرة الجديدة تُدخل بالإنجليزية لتجنب تخمين ترجمة الأسماء والمؤهلات. السجلات العربية القديمة لا تُحذف؛ يُطلب من المالك مراجعتها.

| البيان | مصدره أو قاعدته |
| --- | --- |
| الاسم الكامل | صاحب الحساب؛ 2–120 حرفًا |
| البريد | البريد المعتمد من جلسة الحساب، وليس بريدًا بديلًا يرسله العميل |
| الهاتف | إدخال المالك، صيغة محددة وسبعة أرقام على الأقل |
| الدولة والمدينة/الموقع | إدخال المالك |
| المؤسسة التعليمية والدرجة والتخصص | بيانات التعليم الحقيقي |
| سنة التخرج | سنة من أربعة أرقام ضمن النطاق المتحقق منه |
| مستوى الخبرة | طالب، خريج جديد، مبتدئ، متوسط، خبير |
| اللغات | حتى ثماني لغات محفوظة |
| LinkedIn والموقع المهني | اختياريان؛ الروابط المناسبة تتزامن مع المعرض وCV |
| الخبرة الفعلية | حتى خمس خبرات؛ الشركة والمسمى والتواريخ وحالة العمل الحالي والوصف |

التعليم الأساسي يُدمج مع الملف الموجود دون تكرار نفس سجل التعليم. الخبرة الفعلية منفصلة عن خبرة المحاكاة: العمل على Mizan Trading داخل اللعبة لا يُكتب باعتباره وظيفة حقيقية.

## 5. صورة البروفايل

- اختيارية؛ عدم رفعها لا يمنع استكمال التسجيل.
- المدخلات المدعومة JPG / PNG / WebP، حتى 5MB قبل المعالجة في المتصفح.
- المقاس المحفوظ **512×512 بكسل**، مع قص مركزي مربع وإظهار الصورة بما يملأ الدائرة.
- الخادم يفحص البكسلات ويعيد ترميز الصورة WebP ثابتة، ويزيل EXIF/GPS؛ الأصل لا يُحفظ.
- حجم النسخة النهائية على الخادم لا يتجاوز 120,000 بايت. تُرفض الملفات التالفة والمتحركة وSVG والمدخلات ذات البكسلات الضخمة.
- يمكن رفعها أو استبدالها أو إزالتها من الواجهات المرتبطة بالملف. التغيير ينعكس على معاينة الكارت دون إعادة تفعيل اختيار صورة سبق إخفاؤها.
- صورة واحدة خاصة لكل حساب؛ تُحمّل من هوية الجلسة، ويُمنع بقاء صورة الحساب السابق عند تبديل الحساب أو الخروج.
- الإزالة تحتفظ بحارس إصدار السجل لمنع تبويب قديم من استعادة صورة محذوفة دون قصد.

الصورة **ليست داخل ATS CV أو الصفحة العامة أو تصدير التقدم**. الكارت المهني المنزّل استثناء يختاره صاحبه، ويمكن تنزيله دون صورة.

## 6. الكورسات الخارجية

إضافة وتعديل وحذف حتى **20 كورسًا** لكل حساب، بالحقول الآتية:

- الاسم والجهة التدريبية.
- اسم الكورس والجهة بالإنجليزية للـCV، اختياريا؛ يمكن إبقاء أسماء العرض العربية في البروفايل.
- شهر اختياري بصيغة `YYYY-MM`.
- الحالة: لم يبدأ / جارٍ الدراسة / مكتمل.
- ملاحظات ما تم تعلمه، حتى 1000 حرف.

هذه بيانات يصرح بها صاحب الحساب، وليست تقييمًا من المنصة. لا تُضاف XP أو مهارات Verified لمجرد كتابة كورس، ولا تُختلق نسبة تقدم رقمية له.

### علاقة الكورس بالسيرة

- الحفظ أو تغيير الحالة أو الحذف ينعكس على المصدر المستخدم في CV؛ لا حاجة إلى إعادة «إنشاء» السيرة يدويًا.
- الكورسات السابقة للإصدار الأخير تُقرأ أيضًا من المصدر الحالي.
- الكورس «لم يبدأ» لا يدخل CV. الجاري والمكتمل يظهران بالحالة الفعلية تحت `Courses (self-reported)`.
- الاسم الإنجليزي الاختياري يُستخدم عند وجوده؛ وإلا يُستخدم الاسم الأصلي إذا كان مناسبًا للسيرة الإنجليزية.
- لا تُختلق ترجمة لكورس عربي دون اسم إنجليزي. يبقى في البروفايل مع تنبيه بدل ادعاء ترجمة صحيحة.
- السيرة تختار مبدئيًا حتى ستة كورسات، المكتمل أولًا ثم الأحدث. قد تستبعد مزيدًا لتناسب الصفحتين دون حذفها من البروفايل.

## 7. الشهادات وصورها

حتى **20 شهادة**: الاسم، الجهة المانحة، شهر إصدار اختياري، رقم شهادة اختياري، وصورة إلزامية عند الإضافة.

- JPG / PNG / WebP حتى 5MB قبل تجهيز المتصفح.
- أقصى ضلع للنسخة المعدة 1600 بكسل، مع الحفاظ على نسبة الأبعاد والمستند كاملًا؛ لا قص مربع للشهادات.
- فحص خادمي وإعادة ترميز WebP ثابتة بدون EXIF/GPS؛ لا حفظ للملف الأصلي.
- حد الصورة المشفرة 900,000 حرف، وحد جسم طلب الرفع 950,000 بايت.
- لا دعم حاليًا لرفع PDF أو SVG أو GIF أو جلب صورة من رابط خارجي.
- معاينة خاصة في نافذة تدعم لوحة المفاتيح وEscape، دون نشر عنوان صورة عام.
- الحذف بعد التأكيد يزيل الصورة المخزنة؛ لا توجد سلة استرجاع يُوعد بها المستخدم.
- كل شهادة موسومة «مرفوعة · غير موثقة». الرفع لا يثبت صحة الجهة ولا يمنح اعتمادًا أو مهارة مقيمة.

تُحفظ الصور منفصلة عن قائمة بيانات الشهادات حتى لا تُنقل كل الصور عند قراءة البروفايل. حساب آخر لا يستطيع فتح شهادة بمجرد معرفة UUID.

بيانات الشهادة الإنجليزية المناسبة يمكن أن تظهر نصيًا تحت `Certificates (self-reported)`، مبدئيًا حتى أربع شهادات حديثة. **الصورة ورقم الشهادة الخاص لا يدخلان CV**. حقول الاسم الإنجليزي البديل أُضيفت للكورسات؛ لا توجد حاليًا حقول ترجمة منفصلة مماثلة للشهادات.

## 8. التقدم واللعب وملخص القدرات

الرحلة مترابطة: البيانات الشخصية → أساسيات المحاسبة → أول وردية → أدلة المهارات → السيرة الإنجليزية. التقدم المهاري مصدره ما قُبل على الخادم، وليس اكتمال الاسم والتليفون أو إدخال كورسات خارجية.

- الوحدة التمهيدية تشمل 11 مهمة مصححة على الخادم.
- أول وردية تشمل خمس محطات، مع حالات العمل ومراجعة اليومية والأستاذ وفق قواعدها.
- ورقة الجداول داخل كمبيوتر المكتب تستخدم بيانات محاسبية فعلية للمحاكاة، لا مجرد سؤالين منفصلين عن مكان العمل.
- قبول الصيغ والنتائج يثبت استخدامًا أساسيًا للجداول، وليس إتقان برنامج Microsoft Excel كاملًا.
- ملخص «أنا أقدر أعمل إيه؟» مشتق من التاسكات المقبولة بدل عبارات عامة مثل «مجتهد وطموح».
- ملف المهارات الكامل يحتفظ بالأدلة حتى إذا اختُصرت النتائج في CV.
- إسقاط تقدم First Shift القديم في السيرة يبقى ممارسة محاكاة، ولا ينشئ تلقائيًا دليلًا رسميًا جديدًا أو Verified أو نتيجة منافسة.

لا تتغير قواعد الدفاتر أو التصحيح أو المنافسات لتجميل البروفايل.

## 9. السوشيال والتوفر المهني

الروابط المدعومة: LinkedIn وGitHub وFacebook وInstagram وموقع/Portfolio.

- روابط HTTPS مباشرة، مع التحقق من نطاق الشبكة، دون كلمة مرور أو منفذ مخصص أو query تتبع أو fragment.
- رابط الموقع العام يجب أن يكون نطاقًا مناسبًا، لا localhost أو عنوان IP محليًا.
- الروابط الخارجية لا ترسل referrer وتستخدم حماية النوافذ الخارجية.
- حالة اختيارية: متاح لتدريب أو للعمل، مع الدور المطلوب. هذا إعلان رغبة، لا حكم بأن الشخص مؤهل لمجرد استكمال بياناته.
- LinkedIn والموقع المهني الصالحان مشتركان بين محرر البيانات والمعرض وCV؛ التعديل في أحدهما ينعكس على الباقي.
- GitHub وFacebook وInstagram تخص البروفايل والكارت؛ لا تُحشر في ATS CV.
- الرابط القديم الذي لا يجتاز قواعد المشاركة الآمنة لا يُنسخ تلقائيًا إلى الصفحة العامة، ولا يُحذف من البيانات الخاصة لمجرد قدمه.
- تعديل الروابط لا يفعّل نشر البروفايل. إذا كان المالك قد وافق سابقًا على مشاركة السوشيال، تظهر روابطه الحالية ضمن اختياره القائم.

## 10. أفضل ثلاثة أعمال

يمكن تثبيت **ثلاثة أعمال كحد أقصى** من الأعمال المتاحة بعد قبول مهامها. المعاينة توضح أنها أوراق تدريبية أُعيد بناؤها من مواصفات المهام المقبولة، لا ملفات عملاء حقيقيين ولا ملف Excel أصليًا رفعه الطالب.

| العمل | ما تعرضه المعاينة وما يثبته |
| --- | --- |
| اليومية | ستة قيود متوازنة مع مراجع مستندات المحاكاة؛ ممارسة القيد المزدوج |
| أستاذ النقدية | الحركات والترحيل ورصيد الإقفال 84,000 جنيه، مطابقًا لليومية |
| ميزان المراجعة | ثمانية حسابات، 127,000 جنيه مدين و127,000 جنيه دائن |
| فحوص ورقة العمل | SUM وفحص الفرق بين المدين والدائن، مع نتائج وصيغ الفحص |

التوازن ليس دليلًا على عدم وجود أي خطأ محاسبي. لا يظهر عمل تسوية بنكية أو مهارة أخرى لمجرد رغبة المستخدم؛ توسيع المعرض يحتاج ربطًا بنواتج قبولها المؤكدة. الكورسات والشهادات المرفوعة لا تفتح أعمالًا مقيمة تلقائيًا.

## 11. الكارت المهني وبطاقة الإنجاز وQR

| العنصر | الكارت المهني | بطاقة الإنجاز |
| --- | --- | --- |
| الغرض | تعريف مهني بصاحب الحساب وروابطه | مشاركة مهارة أثبتتها مهمة تدريبية |
| المقاس | PNG، 1600×1100 | PNG، 1200×900 |
| المصدر | بيانات البروفايل الحالية | العمل أو المهمة المقبولة |
| الصورة | اختيارية، ويمكن إخفاؤها | ليست بديلًا عن إثبات المهمة |
| المحتوى | الاسم والدور والتوفر والروابط وQR | الاسم والمهارة والمهمة وتوضيح المحاكاة |
| المشاركة | تنزيل المالك وإرساله بنفسه | تنزيل لإرفاقه بمنشور مثل LinkedIn |

إنشاء PNG وQR يتم محليًا؛ لا تُرفع صورة الحساب إلى خدمة QR خارجية، ولا يُنشر منشور تلقائي على حساب سوشيال.

الكارت من البروفايل الحقيقي، وليس كارتًا ببيانات تجريبية. عند غياب الصورة تُستخدم بدائل العرض المناسبة دون اختلاق صورة شخص.

**الباركود هنا QR ثنائي الأبعاد** يفتح الرابط العام الحقيقي. تنزيل الكارت يحتاج تفعيل رابط المشاركة أولًا، حتى لا يحتوي QR وهميًا أو وجهة غير موجودة.

الروابط قابلة للنقر في المعاينة داخل الموقع. في PNG تصبح نصوصًا وليست أزرارًا؛ يستخدم المستلم QR أو يكتب الرابط.

**فرق خصوصية مهم:** اختيار الحقول العامة يحدد ما يظهر عند فتح QR، وليس ما يُطبع في صورة الكارت. الصورة المنزلة تحتوي الاسم والروابط المحفوظة والصورة إن اختارها المالك، ويُوضّح ذلك قبل التنزيل. إلغاء الرابط لا يسحب نسخ PNG سبق تنزيلها أو مشاركتها.

## 12. الرابط العام والتحكم في المشاركة

المسارات الحقيقية: `/ar/portfolio/<opaque-token>` و`/en/portfolio/<opaque-token>`.

- المشاركة مغلقة افتراضيًا، ويجب أن يفعّلها صاحب الحساب صراحة.
- يختار المالك إظهار الاسم أو السوشيال أو التوفر أو ملخص القدرات، ويختار الأعمال العامة من أعماله المثبتة.
- التوكن عشوائي 128-bit، لا يُشتق من الاسم أو رقم المستخدم.
- الزائر يرى الحقول المختارة فقط، ولا تُحمّل له بيانات المالك الخاصة داخل HTML أو RSC.
- الصفحة العامة لا تحتوي البريد أو التليفون أو user ID أو الصورة أو صور الشهادات أو الكورسات الخاصة أو CV كاملًا.
- إلغاء المشاركة يجعل الرابط السابق غير متاح؛ عند التفعيل مجددًا يتولد رابط جديد.
- الروابط غير الصحيحة أو الملغاة تعطي 404، لا حلقة تحويل إلى تسجيل الدخول.
- الصفحات لا تُفهرس ولا تُدرج في sitemap؛ تستخدم no-store وnoindex/noarchive وno-referrer.
- لا يوجد دليل عام لكل المستخدمين أو بحث عنهم بأرقام متسلسلة.

المشاركة الطوعية لا تغير حماية الصور أو Better Auth. الرابط العام لا يغني عن موافقة المالك على مشاركة ملف CV أو صورة الكارت خارج الموقع.

## 13. السيرة الإنجليزية المختصرة وربطها بالبروفايل

السيرة دائمًا إنجليزية وLTR، سواء فُتحت من الواجهة العربية أو الإنجليزية.

### مصادرها

1. البيانات الشخصية والتعليم والخبرة الفعلية والبريد المعتمد من الحساب.
2. بيانات الكورسات والشهادات الخاصة المناسبة، بما فيها السجلات القديمة.
3. أدلة المهام المقبولة على الخادم.
4. إسقاط محاكاة First Shift الموجود لصاحب الحساب، بتوصيفه التدريبي الصحيح.
5. تفضيلات الدور المهني وروابط LinkedIn والموقع المناسبة.

`GET /api/v1/me/cv?role=<role-id>` يقرأ المصدر الحالي في transaction متسقة. قراءة السيرة لا تُجري migration أو backfill ولا تضيف تاريخًا جديدًا في كل فتح.

حفظ البيانات الشخصية أو الكورسات أو الشهادات أو الروابط أو التقدم المشمول يعيد اشتقاق نسخة CV في transaction الحفظ نفسها؛ المقارنة بالمحتوى تمنع تكرار نسخة تاريخية مطابقة. فتح الصفحة والتحديث المرتبط بالمزامنة يقرآن النسخة الحالية، ويوجد تحديث يدوي عند الحاجة.

إذا فشلت قراءة حساب المستخدم، لا نعرض له نسخة ضيف محلية بديلة قد تكون خاطئة؛ يتوقف التنزيل حتى ينجح تحميل المصدر الصحيح. تجربة الضيف المحلية السابقة تبقى مستقلة.

### المحتوى والاختصار

- عمود نصي واحد وعناوين إنجليزية واضحة: التواصل والملخص والخبرة والتعليم والمهارات وخبرة المحاكاة والكورسات والشهادات واللغات والروابط المهنية.
- لا صورة أو QR أو XP أو نسبة اكتمال بيانات أو «درجة ATS» مختلقة.
- القيود الستة تُجمع في نتيجة محاسبية واحدة بدل ست فقرات مكررة؛ الأستاذ وميزان المراجعة وفحوص الجداول نتائج مختلفة.
- الخبرة الحقيقية منفصلة عن `Accounting Simulation Experience`، مع بيان أنها تدريب وليست توظيفًا.
- الكلمات المهنية تأتي من المهارات والنتائج المدعومة؛ لا حشو كلمات دالة أو وعد بتقييم ATS أو وظيفة.

| العنصر | الحد الأولي لاختيار محتوى CV |
| --- | --- |
| الخبرة الفعلية | أحدث ثلاث خبرات، والعمل الحالي أولًا؛ وصف مختصر |
| التعليم | سجلان |
| المهارات الأساسية / الممارسة | حتى ثماني مهارات لكل مجموعة |
| نتائج المحاكاة المختلفة | ست نتائج |
| الكورسات | ستة، مكتملة أو جارية |
| الشهادات | أربع، بيانات نصية فقط |
| اللغات | ست لغات |
| الملخص / العنوان | حتى 280 / 140 حرفًا |

الحدود أولية؛ قد يستبعد قياس الطباعة محتوى إضافيًا. السجلات الكاملة والأدلة لا تُحذف، ويظهر عدد المحتوى المستبعد أو المحتاج للإنجليزية في الواجهة. لا توجد ترجمة تلقائية تخمينية للمؤهلات والخبرات والكورسات والشهادات العربية.

### الصفحتان والتصدير

- حد الصفحتين مطلب لهذا المنتج، وليس ادعاء أن كل معايير CV العالمية تفرض صفحتين.
- A4، هوامش 12mm، عرض محتوى 186mm، خط Arial 10.5pt.
- اختيار محافظ للمحتوى ثم قياس DOM بعرض الطباعة الفعلي وتقسيمه إلى صفحتين كحد أقصى.
- لا يُصغّر الخط لإخفاء الزيادة، ولا يُقص النص خارج الصفحة؛ يحتفظ البروفايل بالمحتوى الكامل.
- نسخة النص القابلة للتنزيل تطابق المحتوى المختار المعروض، لا dump لكل بيانات الحساب.
- حفظ PDF من نافذة الطباعة، مع إخفاء التنقل والأزرار وأدوات القياس وإظهار ترقيم الصفحات.

## 16. حماية البيانات وحدود الادعاء الأمني

- هوية المالك من جلسة الخادم، لا `userId` قابل للتزوير من المتصفح.
- تحقق صارم من الأوامر والحقول؛ لا قبول لحقول إضافية تمنح اعتمادًا أو مهارة.
- التحقق من Origin للكتابة، وحدود معدل الطلبات وحجم المدخلات.
- حارس الحساب عند تغير الجلسة، وحارس revision لمنع استبدال تعديل تبويب آخر؛ التعارض يعيد 409.
- الردود الخاصة تستخدم `Cache-Control: private, no-store`؛ الطلب المجهول الخاص يعيد 401، ومحاولة قراءة شهادة حساب آخر تعيد 404.
- المعاملات الكتابية المناسبة Serializable؛ قراءة CV متسقة دون كتابة تاريخ عند كل GET.
- صور الحساب والشهادات والتوكن وإعدادات النشر لا تدخل التصدير العام للتقدم.
- LinkedIn والموقع المهني قد يظهران في نسخة المالك الخاصة القائمة لأنهما من بيانات تواصله؛ هذا ليس نشرًا عامًا.
- المشاركة العامة مبنية على DTO محدد، لا تسلسل كل سجل الحساب.
- الاختبارات تستخدم حسابات وصورًا وشهادات وهمية وقاعدة محلية معزولة؛ تقارير QA تحت `artifacts/` مستبعدة من Git.

هذه حماية وظيفية مختبرة ضمن النطاق، وليست إعلان اختبار اختراق شامل أو اعتماد امتثال قانوني. لم تُحذف أعمال Backend أو Better Auth أو بيانات الإنتاج، ولم يتغير النظام المحاسبي أو تُنشر أسرار.

## 18. طريقة الاستخدام لصاحب الحساب

1. أنشئ الحساب ثم سجل الدخول واستكمل بيانات السيرة بالإنجليزية، مع تعليمك وخبرتك الفعلية إن وجدت.
2. افتح البروفايل وارفع الصورة اختياريًا؛ تستخدم نفس الصورة في معاينة الكارت.
3. من الكورسات أضف الاسم والجهة والحالة؛ للكورس العربي اكتب الاسم والجهة الإنجليزية للـCV.
4. من الشهادات أضف البيانات وارفع صورة واضحة كاملة؛ افهم أنها خاصة وغير موثقة تلقائيًا.
5. أضف روابط السوشيال الصحيحة وحالة التوفر إن أردت.
6. أكمل المهام داخل التعلم واللعب؛ تظهر القدرات والأعمال المتاحة من القبول الفعلي.
7. ثبت حتى ثلاثة أعمال، ثم اختر ما تريد نشره وفعّل الرابط العام إذا رغبت في المشاركة.
8. راجع الصفحة العامة باعتبارك زائرًا، ثم نزّل الكارت مع الصورة أو بدونها وبطاقة الإنجاز المطلوبة.
9. افتح CV؛ راجع المحتوى والتنبيهات واحفظ PDF أو النص. البيانات الزائدة محفوظة في البروفايل ولو لم تُطبع.
10. عند الرغبة في إيقاف المشاركة ألغِ الرابط؛ تذكر أن الصور والملفات التي أرسلتها سابقًا لا تُسحب تلقائيًا.

## 19. تفسير الحالات الشائعة

| الحالة | التفسير أو الإجراء |
| --- | --- |
| الكورس لا يظهر في CV | تأكد أنه جارٍ أو مكتمل، وله اسم وجهة مناسبين بالإنجليزية؛ قد يستبعده حد المحتوى مع تنبيه |
| الشهادة لا تظهر بصورتها في CV | مقصود: السيرة نصية؛ البيانات المناسبة فقط تظهر، دون الصورة أو الرقم الخاص |
| الكارت لا ينزل قبل تفعيل المشاركة | يحتاج QR لرابط حقيقي؛ فعّل المشاركة باختيارك أو اتركها خاصة |
| الصورة في الكارت لا تظهر | تأكد من حفظها للحساب الحالي ومن اختيار تضمين الصورة |
| اكتمال البيانات 100% لكن المهارات ليست مكتملة | المقياسان مختلفان؛ المهارة تحتاج مهام مقبولة، لا بيانات شخصية فقط |
| تعديل من تبويب آخر لم يُقبل | تعارض revision يحمي البيانات؛ حدّث المصدر ثم راجع التعديل |
| فشل تحميل CV | أعد التحديث بعد استقرار الاتصال؛ لا يُستخدم بديل محلي باسم الحساب عند الخطأ |
| رابط مشاركة قديم يعيد 404 | قد يكون أُلغي؛ إعادة التفعيل تولد رابطًا جديدًا |
| الواجهة تبدو قديمة | حدّث الصفحة؛ تحقق من النسخة المنشورة بدل الاستدلال من متصفح يحتفظ بالواجهة القديمة |
| أدوات الشهادات الخاصة غير موجودة للضيف | يلزم تسجيل الدخول؛ معاينة الضيف لا تدير بيانات الحساب الخاصة |

## 20. التحقق المنجز للإصدار الوظيفي الأخير

هذه نتائج الإصدار المنفذ قبل إعداد الوثيقة، وليست نتائج تشغيل اختبارات جديدة بسبب تعديل Markdown.

- `npm run check` نجح: lint دون تحذيرات، TypeScript دون أخطاء، **621 اختبارًا في 73 ملفًا**، وبناء الإنتاج.
- جدول مسارات Next.js شمل صفحات login/signup المحلية ومسارات CV والمشاركة وBetter Auth.
- QA المتصفح المحلي: **668 فحصًا** دون أخطاء تشغيل، بالعربية والإنجليزية، عرض 1440 و390 بكسل، ومعاينة عامة على 320 بكسل.
- شمل التسجيل ثم الدخول والإعداد، أنواع المستخدمين الأربعة، رفع الصورة وإزالتها، CRUD الكورسات والشهادات وانعكاسها على CV، الروابط الإنجليزية، عزل الحسابات، الموافقة العامة والإلغاء، وOrigin/revision.
- فُحصت صور PNG الحقيقية بمقاسي 1600×1100 و1200×900.
- خمسة PDF فعلية: أربع حالات عادية صفحة واحدة، وحالة كثيفة صفحتان؛ استُخرج النص وراجعت صور الصفحات الست. الخط 10.5pt دون تقليص أو قص.
- ظهر أثناء مراجعة الطباعة عيب خلفية زائدة في الحاوية؛ أُصلح ثم أعيدت الحزمة كاملة.
- بعد النشر: **130 فحص إنتاج قراءة فقط**؛ 16 للمعرض، 54 لرحلة الطالب والواجهات الخاصة، 40 للمصادقة، و20 للسيرة الجديدة.

## 22. غير منفذ أو غير مضمون

- لا اعتماد تلقائي للشهادات ولا تحقق رسمي من الجهة المانحة.
- لا رفع PDF للشهادات حاليًا، ولا صورة عامة تلقائية لصاحب الحساب.
- لا نشر تلقائي على LinkedIn أو دخول إلى حسابات السوشيال.
- لا ضمان درجة ATS أو مقابلة أو وظيفة، ولا احتساب كورس مكتوب كمهارة مصححة.
- لا تحويل محاكاة اللعبة إلى خبرة توظيف حقيقية، ولا إتقان Excel كاملًا من الصيغ الأساسية.
- معرض الأعمال الحالي محدود بالأعمال المدعومة الموضحة؛ إضافة أعمال أخرى تحتاج دليل قبول مناسب.
- لا سحب لصور الكروت أو ملفات CV التي شاركها المستخدم بعد تنزيلها.
- لا حذف لبيانات الحساب الزائدة بسبب اختصار CV، ولا إعادة تهيئة قاعدة البيانات.
- تشغيل Google أو خدمات البريد يتطلب إعداد مزوديها؛ تغييرات البروفايل لا تثبت وحدها تشغيل هذه الخدمات.
