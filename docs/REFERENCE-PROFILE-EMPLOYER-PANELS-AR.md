# مطابقة قسمي البروفايل والمرشحين للمرجع

## نطاق التغيير — 13 أكتوبر 2026

تم تعديل نظرة البروفايل العامة وقائمة المرشحين ومعاينة المرشح فقط. لم يتغير الهيدر أو الصورة الشخصية أو أنظمة المحاسبة أو مصدر بيانات الـCV أو موافقات نشر البيانات.

## البروفايل

- ترتيب ثابت مثل المرجع: المعلومات الشخصية يسارًا، والتقدم والمهارات والأعمال والشهادات يمينًا، حتى في الواجهة العربية.
- الأيقونة والعنوان والقيمة داخل كل صف في موضع واحد، بدل فصل العنوان عن قيمته على طرفي الكارت.
- كروت ومسافات أكثر اختصارًا، بنفس درجات الكحلي والأزرق والأخضر والبرتقالي والوردي الموجودة في المرجع.
- تفاصيل أدلة المهارات تظل متاحة لقارئ الشاشة وفي تبويب المهارات الكامل، دون تكديس تفاصيل التقييم داخل الملخص المصغر.
- النصوص تظل مترجمة للعربية والإنجليزية؛ ترتيب المكونات لا يغيّر لغة بيانات المستخدم.

## المرشحون ومعاينة المرشح

- قائمة يسارًا ومعاينة يمينًا، ضمن إطار محدود بعرض 1200px مع تجاوب للموبايل.
- كروت أصغر تتضمن الصورة، الاسم، الدور، المكان إن تمت مشاركته، مهارتين وعدد المهارات الباقية.
- رأس المعاينة: الصورة يسار الاسم، وأزرار الإجراءات والقائمة المختصرة يمينًا؛ القائمة ذات الثلاث نقاط تفتح إجراء الإغلاق الحقيقي، وليست زرًا شكليًا.
- خمسة أقسام متتابعة بفواصل: نبذة، معلومات أساسية، مهارات، عمل مميز من المحاكاة، وشهادات مضافة من المرشح.
- أزرار عرض كل المهارات والشهادات وعرض العمل تفتح التبويبات الفعلية.
- الدرجات المتاحة تُعرض أولًا في ملخص المهارات. المهارة التي ليس لها تقييم كافٍ لا تحصل على نسبة أو درجة مخترعة.
- حالة قبول العمل تظهر منفصلة عن نص كونه محاكاة تدريبية. الشهادات تظل مضافة من صاحب الحساب وليست توثيقًا من المنصة.

## ضوابط البيانات

لا نسخ لأسماء المرجع أو أعداد 124/12/6/4/8 أو نسب الملاءمة 78%. القوائم والأعداد والدرجات تأتي من بيانات الحساب والأدلة الموجودة. لا تعديل لإعدادات الظهور أو كشف بيانات اتصال أو صور شهادات خاصة أو إنشاء حسابات إنتاج للاختبار.

## التحقق

- `npm run check`: lint وTypeScript والاختبارات وبناء الإنتاج.
- اختبارات واجهة تثبت ترتيب المقاطع، الدرجات الحقيقية، أزرار عرض الكل، وعدم استبدال البيانات برقم مطابقة وهمي.
- `node scripts/talent-platform-qa.mjs --panels-reference`: حسابات وقاعدة PostgreSQL محلية مستقلة، وصور ومراجعات عند عروض 1920 و1440 و1024 و390 حسب الصفحة، باللغتين والوضع الداكن.
- صور المقارنة محفوظة محليًا في `artifacts/reference-panels/qa`، وليست ملفات عامة أو جزءًا من Git.
- فحص الإنتاج للقراءة فقط بعد النشر.

النتيجة المحلية النهائية: نجاح `npm run check` مع 656 اختبارًا في 79 ملفًا، ونجاح البناء. اكتمل سكربت المتصفح بـ312 فحصًا وخرج بنجاح بعد مراجعة الصور العربية والإنجليزية والمحاذاة والموبايل والخصوصية والتبديل بين الحسابات.
