# نشر بديل على Render — 9 أكتوبر 2026

## السبب والنطاق

رابط Vercel وعنوان vercel.com نفسه انتهت مهلة اتصالهما من الجهاز، بينما GitHub وواجهة Render استجابا. DNS المحلي وGoogle أعادا نفس عنواني الموقع؛ هذا لا يحدد إن كان سبب انقطاع الوصول من الجهاز أو الراوتر أو مزود الخدمة. فحص الإنتاج الخارجي الجديد نجح في 160 فحصًا:

https://github.com/AhmedMohamed500/Debit-Credit/actions/runs/37944413873

المستخدم وافق على تجهيز نشر بديل. هذا نشر إضافي فقط، وليس حذفًا لـVercel أو استبدالًا لقاعدة الإنتاج.

## إعداد النشر

- `render.yaml` يحدد خدمة Next.js فعلية على Node 22 بخطة `free`، وليس تصدير صفحات ثابتة يعطل Backend/Auth.
- الفرع `codex/render-fallback` مع نشر تلقائي معطل؛ لا توجد وظائف دورية أو إبقاء مصطنع للخدمة نشطة.
- بناء المشروع يولد Prisma Client فقط؛ لا توجد أوامر ترحيل أو reset أو seed.
- `DATABASE_URL` يجب أن يُضبط سرًا على قاعدة الإنتاج الموجودة، باستخدام `DATABASE_DRIVER=postgres`. لا تستخدم قاعدة Neon المعزولة الخاصة بالاختبار.
- Render يولد سر Better Auth جديدًا لهذه الاستضافة، ويضبط عنوان المصادقة تلقائيًا من `RENDER_EXTERNAL_URL`؛ لا يعيد المستخدم إلى Vercel.
- لا توجد بيانات Google؛ لا تدّعي عمل Google OAuth.
- فحص الصحة `/api/auth/get-session` لا يمر إذا كانت المصادقة غير مهيأة.

## حالة التنفيذ

تم إعداد ملفات النشر فقط. لم يُنشأ رابط Render فعلي بعد، ولم تُرسل أسرار قاعدة الإنتاج إلى Render. إضافة Render مثبتة الآن لكن ربط الحساب لم يتأكد بعد، ولا يوجد ملف اعتماد CLI محلي له. أدوات التحكم بالمتصفح تعطلت بخطأ تهيئة kernel assets حتى بعد إعادة التهيئة. لا تُعامل نجاح تجهيز الملف كأنه نجاح نشر.

تجهيزات البديل تُحفظ في فرع منفصل `codex/render-fallback`، وليس على `main` أو فرع Vercel الحالي. إعداد `vercel.json` على هذا الفرع يمنع إنشاء Vercel preview له، مع الإبقاء على نشر `main` طبيعيًا.

## القيود

الطبقة المجانية مخصصة للتجربة؛ تتوقف الخدمة بعد 15 دقيقة دون طلبات وقد تستغرق نحو دقيقة للاستيقاظ. لا تُضاف بطاقة دفع أو ترقية مدفوعة. إذا كان الحساب الحالي عليه وسيلة دفع، راجع حدود الصرف قبل التشغيل. لا تنشئ قاعدة Render المجانية التي تنتهي بعد 30 يومًا.

## بعد ربط الحساب

تحقق من الحساب والخطة والموارد الموجودة؛ أنشئ الخدمة الجديدة فقط إذا لم يوجد نشر مناسب لهذا المشروع. اضبط URL قاعدة الإنتاج دون طباعته أو إدراجه في Git، وانتظر `live`. اختبر من جهاز المستخدم صفحات `/ar` و`/en` و`/ar/login` و`/ar/signup` و`/en/login` و`/en/signup` وواجهة المصادقة. لا ترسل بيانات حساب حقيقي أو تنشئ مستخدمًا اختباريًا دون إذن.
