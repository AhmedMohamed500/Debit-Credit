# منهج الطالب والسيرة المحاسبية التلقائية

تاريخ العمل: 10 أكتوبر 2026. هذا التقرير يصف الوحدة المنفذة فقط، وليس ادعاء اكتمال منهج التأهيل لسوق العمل.

## رحلة الطالب

إنشاء حساب بالبريد ← تسجيل دخول منفصل ← استكمال بيانات CV الخاصة بالحساب ← الرئيسية الخاصة بالمستخدم ← الوحدة الأولى. الدخول عبر البريد أو Google المجهز يمر بمسار `/{locale}/auth/continue` الفعلي قبل الوجهة الداخلية المطلوبة. Google غير مفعّل دون إعداد بياناته.

المطلوب: الاسم الكامل، الهاتف، إيميل الحساب غير القابل للتزوير من الطلب، الدولة والمدينة، الجامعة/المؤسسة، المؤهل والتخصص وسنة التخرج أو التخرج المتوقع والمرحلة المهنية. الروابط واللغات والخبرة الحقيقية السابقة اختيارية. لا نطلب صورة أو رقمًا قوميًّا أو تاريخ ميلاد أو عنوانًا تفصيليًّا.

لا تعتمد ضرورة الاستكمال على `completed: true` في localStorage. الحفظ والتحقق بالخادم مع ملكية من جلسة الدخول، ورفض إدخال صاحب حساب آخر أو الإيميل أو علامة اكتمال مزيفة. لا تدخل البيانات الشخصية إلى المنافسات أو ملفات الشركات التجريبية. تبقى إعدادات الخصوصية القديمة محفوظة؛ الافتراضي خاص والهاتف والإيميل مخفيان عن معاينات الشركات.

## الوحدة الأولى: من المستند إلى الدفاتر

ملف افتراضي لشركة ميزان للتجارة والخدمات، بالجنيه المصري، دون أرصدة افتتاحية، وبمبالغ دون ضرائب. لا تتضمن الوحدة إهلاكًا أو قيمة مضافة أو إقفالًا كاملًا؛ هذه حدود تعليمية صريحة.

11 تاسك بالترتيب: مراجعة نسخة فاتورة مكررة؛ ست معاملات مستقلة لرأس المال والمعدات والمخزون الآجل والخدمات الآجلة وتحصيل العميل والإيجار؛ رصيد أستاذ النقدية؛ إجماليات ميزان المراجعة؛ تصحيح خطأ تصنيف متوازن؛ صيغ SUM وفرق المدين والدائن في ورقة عمل أساسية.

المراجع تربط كل قيد بمستنداته. الترحيل والإجماليات تُشتق من القيود المقبولة فقط: رصيد النقدية 84,000، وإجمالي كل طرف في ميزان المراجعة 127,000 جنيه. ملف CSV حقيقي متوافق مع برامج الجداول يضم الأرصدة المقبولة وصيغ الإجماليات، دون بيانات الطالب. هذا ليس تدريب Excel شاملًا أو شهادة إتقان.

الخادم يفرض ترتيب التاسكات ويتحقق من الحسابات والمبالغ والإجماليات والصيغ، ويسجل المحاولات. لا يزيد الإنجاز أو الدليل بإعادة إرسال تاسك مقبول. لا تضيف الإجابة الخاطئة إنجازًا إلى CV. إعادة المحاولة الصحيحة تُسجل تدريبًا، ولا تتظاهر بأنها حل مستقل من أول محاولة. لا تغييرات في دليل الحسابات المحمي أو محركاته الموجودة، ولا مسح أو إعادة ضبط قاعدة بيانات.

## CV التلقائي وATS

كل تاسك مقبول يولّد أدلة مهارات وصياغة عربية وإنجليزية محددة للفعل المحاسبي، تلقائيًا دون زر «أضف للسيرة». يُعاد بناء نسخة CV خاصة بالخادم داخل نفس معاملة قبول التاسك، وبمجرد حفظ البيانات الشخصية أو تعديل ملف CV/الدور. المسار الخاص `/api/v1/me/cv` لا يعمل إلا لصاحب الجلسة.

يستمر دعم أدلة أول وردية والتسوية البنكية الموجودة دون تحويلها إلى شهادة أو خبرة توظيف. أول وردية الحالية تظل محاكاة/نسخة تقدم محلية مدعومة بسحابة؛ لا نُدّعي أنها تقييم مهني مستقل موثق بالخادم.

السيرة تفصل **خبرة المحاكاة المحاسبية** عن الخبرة الحقيقية التي يدخلها الطالب بنفسه. الكلمات المحاسبية مستمدة من أدلة التدريب ومرتبطة بالدور المستهدف. الاستنتاج «Demonstrated» للوحدة التمهيدية يحتاج ثلاث أنشطة مستقلة ناجحة؛ النشاط الواحد يظل تدريبًا. لا نضيف CPA/CMA أو ERP أو ضرائب أو خبرة عمل أو نسب تحسن مختلقة.

التصدير نص قابل للقراءة والاختيار، بعناوين قياسية وعمود قراءة واحد، وبلا حشو كلمات دالة. الروابط وتواريخ الخبرة محفوظة في النص؛ يمكن الطباعة/الحفظ PDF. فحوص التنسيق ليست درجة من شركة ATS ولا تضمن اجتياز نظام أو الحصول على وظيفة.

## حدود المرحلة التالية

وحدات AP/AR التفصيلية، تسويات البنوك المتقدمة، المخزون والتكلفة، الأصول والإهلاك، الرواتب، الضرائب المحلية، الإقفال والقوائم الكاملة، Excel العملي المتقدم وERP والتواصل المهني والأخلاقيات تُبنى لاحقًا. لا تظهر كمهارات مكتسبة بسبب إنهاء هذه الوحدة.
