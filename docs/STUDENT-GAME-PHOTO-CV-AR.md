# الـCV الإنجليزي وصورة الطالب ومكتب التدريب داخل اللعبة

## التغيير

الواجهة السابقة كانت صفحة نموذج مستقلة. أصبحت الوحدة جزءًا من مركز اللعب، بنفس صورة مدينة أول وردية وبواباتها: مراجعة المستندات، مكتب القيود، الأستاذ، ميزان ومراجعة، وورقة العمل. المسار الرئيسي `/ar/game/student` أو `/en/game/student`، مع الاحتفاظ بـ`/student` وتقدم الوحدة الموجود. الرئيسية للمستخدم المسجل أصبحت Game Hub الموجود، دون تغيير صفحة التسويق للزائر.

يفتح الملف في مكتب عمل داخل اللعبة، بصندوق عمل، مستندات تدريبية قابلة للفتح حسب مرجعها، قرارات مراجعة واضحة، قيود ودفاتر مقبولة. يمكن إغلاق المكتب وإعادة فتحه دون فقد الاختيار غير المرسل في نفس الصفحة. تبقى اليومية والأرصدة منفصلة عن حالة أول وردية القديمة؛ لا دمج مبالغ شركتين تدريبيتين أو نقل إنجازات خاطئة. لا تغيير في دليل الحسابات أو محرك التقييم أو قاعدة الإنتاج.

## CV إنجليزي

عناوين الوثيقة، المهارات، حالات المهارات، الإنجازات وملخصها الآلي بالإنجليزية، والوثيقة `lang=en` و`dir=ltr` حتى من واجهة عربية. تصدير النص والطباعة لا يحتويان الصورة. لا تُستخدم خلاصة أو عنوان عربي مكتوب سابقًا كملخص إنجليزي؛ يظل الأصل محفوظًا ويُستخدم بديله الآلي المرتبط بالأدلة في السيرة.

يكتب الطالب الاسم والتعليم والمكان واللغات والخبرة الحقيقية بالإنجليزية عند حفظ بيانات CV الجديدة. بيانات الحسابات القديمة لا تُمسح ولا تُترجم بالتخمين؛ تظهر ملاحظة عند الحاجة لمراجعتها بالإنجليزية. التوافق التنسيقي ليس درجة ATS أو ضمان وظيفة.

## صورة البروفايل

اختيارية. يُقبل JPG أو PNG أو WebP حتى 5MB في المتصفح، ويُقصّ المنتصف إلى مربع **512×512** قبل الإرسال. يُفك ترميز الصورة بالخادم ويُعاد إنتاج WebP ثابت دون EXIF/GPS أو ملف أصلي. حد الصورة المحفوظة 120KB؛ صور SVG/GIF والملفات التالفة أو فائقة الأبعاد مرفوضة.

رفع/استبدال/إزالة من إعداد البيانات، حسابي، تعديل الملف المهني أو ملف اللعبة. تظهر نفس الصورة الخاصة في الملف المهني وملف اللعبة وبطاقات اللاعب. ليست إلزامية للتسجيل، ولا تُضاف للـCV أو الترتيب أو معاينات الشركات.

`GET/PUT /api/v1/me/photo` يستمد صاحبه من جلسة الدخول فقط، مع رفض حقول مالك مزورة وفحص revision ومنع تخزين الرد مؤقتًا. لا مسار صورة عامة ولا خدمة خارجية جديدة. صورة واحدة صغيرة لكل حساب في `CloudProgress/profile-photo`، ليست جزءًا من نسخ التقدم أو CV. إزالة الصورة تمحو محتواها مع إبقاء عداد revision لمنع إعادة الكتابة من تبويب قديم. تخزين الصور الأكبر أو النشر العام يحتاج لاحقًا مخزن ملفات وسياسة موافقة مستقلة؛ لم يتم إنشاء خدمة مدفوعة.

## التحقق

اختبارات تلقائية لفك الصور والقص وإزالة metadata ورفض المدخلات المزورة، وCV إنجليزي من واجهة عربية، وحفظ توافق بيانات الطلاب القديمة، وبوابات المدينة وإغلاق/فتح المكتب. QA التسجيل والرفع والتاسكات بالكامل تستخدم PostgreSQL محلية معزولة وبيانات وهمية، وليس مستخدمين إنتاجيين.

نجح `npm run check`: lint وTypeScript و563 اختبارًا في 65 ملفًا، والبناء الإنتاجي. يحتوي جدول Next.js على `/[locale]/game/student` والمسار المتوافق `/[locale]/student` وصفحات الدخول والتسجيل. نجح أيضًا اختبار المتصفح المحلي بـ240 فحصًا للعربية والإنجليزية على عرضَي 1440 و390: التسجيل والدخول والإعداد، رفع الصورة واسترجاعها وإزالتها وعزل الحسابات، فتح المدينة والمكتب، قبول المهام الـ11 وحفظها، وتحديث CV الإنجليزي دون صورة تلقائيًا. تمت مراجعة لقطات المدينة والمكتب على الكمبيوتر والموبايل.

يُنشر هذا التغيير عبر GitHub وربط Vercel الموجود، ثم تُفحص المسارات الإنتاجية بالقراءة فقط؛ لا تشغيل migrate على الإنتاج ولا إنشاء حسابات اختبار فيه ولا كشف بيانات اتصال.
